# FitFlow Frontend Client (Flutter Multiplatform)

Cross-platform client for FitFlow targeting iOS, Android, and Web.

## Prerequisites
- Flutter SDK >= 3.19.0
- Dart SDK >= 3.3.0
- Xcode (for iOS builds) / Android Studio (for Android builds)

## Running the App
```bash
# Get dependencies
flutter pub get

# Run on Chrome (Web)
flutter run -d chrome

# Run on Android/iOS emulator
flutter run
```
